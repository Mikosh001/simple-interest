# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Reporting an issue

Search existing issues before opening a new one. Describe the problem, the steps to reproduce it, and the expected and actual behavior. Include sample inputs when reporting a calculation problem.

## Submitting a change

1. Fork the repository and create a branch for your change.
2. Make a focused change and check that the script still runs in Bash.
3. Update the README when changing how the script works.
4. Commit your change with a clear message and push your branch.
5. Open a pull request explaining the change and how you checked it.

Please follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) in all project interactions.
