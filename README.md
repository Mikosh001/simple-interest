# Simple Interest Calculator

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Input

- `p`: principal amount
- `t`: time period in years
- `r`: annual rate of interest, entered as a percentage (for example, enter `5` for 5%)

## Output

```text
simple interest = p * t * r / 100
```

## Usage

Run the script in Bash (Linux, macOS, or Git Bash on Windows):

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted.
The supplied educational script uses integer arithmetic, so use whole-number inputs; fractional results are truncated.

### Example

```text
Enter the principal:
1000
Enter rate of interest per year:
5
Enter time period in years:
2
The simple interest is:
100
```
